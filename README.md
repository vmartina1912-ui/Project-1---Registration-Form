# Registration Form

## Project Description
This project is a simple Registration Form developed using HTML, CSS, and JavaScript.

## Features
- Name field validation (cannot be empty).
- Email validation (checks valid email format).
- Password validation (minimum 6 characters).
- Real-time validation while typing.
- Submit button remains disabled until all fields are valid.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the index.html file in your browser.
3. Enter your Name, Email, and Password.
4. Complete all validations to enable the Register button.
